after eating a sock. The vacuum's formal, corporate apology — incident
report #4821, sock collected under standard cleaning policy, case closed,
no replacement issued.

Run `python3 main.py` to write the entry to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
